# دعوة راغد &amp; ياسمين — موقع دعوة رقمية فاخرة

موقع دعوة إلكترونية (Digital Invitation) فاخر ومتحرك، مبني بـ React + Vite + GSAP،
يبدأ ببطاقة دعوة مغلقة تُفتح بحركة ثلاثية الأبعاد واقعية، ثم ينتقل الزائر إلى
صفحة رئيسية كاملة (القصة، تفاصيل المناسبة مع عدّاد تنازلي، معرض صور، الموقع،
وتأكيد الحضور RSVP).

## ⚠️ ملاحظة مهمة قبل التشغيل

تم بناء هذا المشروع بالكامل يدويًا (كل الملفات والكود) في بيئة **بدون اتصال
بالإنترنت**، لذلك لم أتمكن من تشغيل `npm install` أو `npm run dev` فعليًا
للتأكد من خلوّه من الأخطاء داخل بيئة البناء نفسها. الكود مكتوب باتباع الأنماط
القياسية لـ React 18 + Vite + GSAP 3 بعناية، لكن **يُرجى تشغيله محليًا أولًا
ومراجعة الـ Console** كخطوة أولى بعد `npm install`. إن ظهر أي خطأ بسيط
(مثلًا اختلاف بسيط في إصدار مكتبة)، أخبرني بنص الخطأ وسأصلحه فورًا.

## التشغيل

يتطلب المشروع Node.js إصدار 18 أو أحدث.

```bash
# 1) تثبيت الحزم
npm install

# 2) تشغيل خادم التطوير (مع Hot Reload)
npm run dev
# افتح الرابط الذي يظهر في الطرفية (عادة http://localhost:5173)

# 3) بناء نسخة الإنتاج النهائية
npm run build

# 4) معاينة نسخة الإنتاج محليًا
npm run preview
```

## التخصيص السريع

كل ما تحتاج تعديله غالبًا موجود في **ملف واحد**:

```
src/data/content.js
```

فيه: اسم العروسين، تاريخ المناسبة، نصوص القصة، تفاصيل المناسبة (التاريخ/الوقت/
القاعة/العنوان)، روابط قسم "قصتنا"، وروابط خرائط جوجل.

### استبدال الصور

الصور الحالية هي **Placeholders** واضحة (مولّدة تلقائيًا) بأسماء منظمة داخل
`src/assets/images/`:

| الملف | الاستخدام |
|---|---|
| `hero.jpg` | خلفية الشاشة الرئيسية (الأفضل: صورة أفقية عالية الجودة) |
| `story.jpg` | صورة قسم "قصتنا" |
| `couple-1.jpg` / `couple-2.jpg` | صور إضافية اختيارية |
| `venue.jpg` | صورة قسم "الموقع" |
| `gallery-1.jpg` … `gallery-6.jpg` | صور معرض الصور (يمكن إضافة المزيد بنفس التسمية + تحديث `content.js`) |

فقط استبدل الملف بنفس الاسم والامتداد، أو غيّر المسار في الملف المرتبط
(`Hero.jsx`, `OurStory.jsx`, `Location.jsx`, `Gallery.jsx`).

### استبدال الموسيقى

`public/music.mp3` هو مقطع صوتي هادئ مؤقت. استبدله بأي ملف mp3 بنفس
الاسم (يُفضّل مقطع مرخّص للاستخدام، مدته 1–3 دقائق مع تكرار سلس).

### الألوان والخطوط

كل نظام التصميم (الألوان، الخطوط، المسافات) موجود في:

```
src/styles/variables.css
```

غيّر قيم `--gold`, `--ink`, `--ivory`, `--rose`... لتغيير الهوية اللونية
بالكامل من مكان واحد.

## الميزات المنفذة

- شاشة تحميل أولية ثم **بطاقة دعوة ثلاثية الأبعاد** تُفتح بالنقر (GSAP timeline
  كامل: تقدّم البطاقة، توهج ضوئي، فتح الغطاء، ظهور تدريجي، ثم انتقال ناعم
  للموقع الرئيسي).
- Navigation ثابت وأنيق يتحول إلى قائمة جوال متحركة على الشاشات الصغيرة.
- Hero بخلفية سينمائية وتتابع ظهور نصوص (Background → Decorative → Text →
  Names → Date → CTA).
- قسم "قصتنا" بأنيميشن ظهور عند التمرير (Scroll Reveal).
- قسم "المناسبة" مع بطاقات تفاصيل وعدّاد تنازلي حي (أيام/ساعات/دقائق/ثوانٍ).
- معرض صور Grid متجاوب مع Lightbox كامل (تكبير، تنقل بالأسهم، إغلاق).
- قسم "الموقع" مع زر لفتح خرائط جوجل.
- نموذج RSVP مع Validation فعلي ورسالة نجاح متحركة بعد الإرسال.
- زر موسيقى خلفية اختياري (لا يبدأ تلقائيًا، التزامًا بقيود المتصفحات).
- خلفية ديناميكية خفيفة (جزيئات + توهجات) بأداء عالٍ (Canvas + transform فقط).
- تصميم متجاوب بالكامل (Mobile → Large screens) بدون Horizontal Scroll.
- احترام `prefers-reduced-motion` لتقليل الحركة لمن يفضل ذلك.
- عنصر زخرفي توقيعي (خط عربي هندسي بسيط) يتكرر كفاصل بين الأقسام بأنيميشن رسم.

## نشر الموقع (Deploy)

بعد `npm run build` سيظهر مجلد `dist/` جاهز للرفع على أي استضافة ثابتة مثل
Vercel أو Netlify أو GitHub Pages أو Cloudflare Pages.
